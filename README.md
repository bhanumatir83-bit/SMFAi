🌟 Overview
Smart Market Finder AI is a modern, responsive web application designed to help consumers discover local fruit and vegetable vendors, explore real-time inventory listings, compare produce prices across markets, and navigate to nearby shops. Built with performance, accessibility, and visual elegance in mind, the platform provides a complete end-to-end shopping experience powered by an intuitive design system and lightweight interactive mapping tools.
🚀 Key Features
🎨 Immersive UI/UX Design: Built with a custom neon dark mode theme, glassmorphic panels, dynamic backdrop blur effects, and micro-interactions.
📍 Interactive Market Map: Uses Leaflet.js and OpenStreetMap to plot nearby vendor locations with interactive markers and quick-view detail popups.
⚖️ Product Price Matrix: Real-time price comparison engine displaying market rates in Indian Rupees ($\text{₹}$) across kilogram, 500g, dozen, and piece units with automatic "Lowest Price" highlighting.
🤖 AI Natural Language Search: Integrated smart assistant allowing users to ask queries like "Where are the cheapest tomatoes near me?" or "Best price for Kashmiri Apples".
🏪 Vendor & Shopkeeper Portal: Dedicated dashboard enabling authorized local vendors to register items, adjust stock status, and update price lists in real-time.
🧭 Integrated Route Navigation: Multi-modal travel estimation (Driving, Biking, Walking) with direct external Google Maps integration.

💻 Getting Started
Quick Start (Single File Setup)
Download or copy index.html from the repository.
Open index.html in any modern web browser (Google Chrome, Mozilla Firefox, Safari, Microsoft Edge).
Click "Explore Markets" on the landing cover screen to launch the application.
No backend server installation or complex build pipelines required!
